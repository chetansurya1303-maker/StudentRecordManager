# StudentRecordManager

A student management project built using Java, MySQL, HTML, CSS, and JavaScript.

## Features
- Add student details through a web interface
- Store student records in a MySQL database
- Connect Java backend to MySQL using JDBC
- Validate student name and age
- Display success and error messages

## Technologies Used
- Java
- MySQL
- JDBC
- HTML
- CSS
- JavaScript

## Database Setup
1. Install MySQL Server.
2. Create a database named `student_management`.
3. Create a `students` table with `id`, `name`, and `age` columns.
4. Configure the `DB_PASSWORD` environment variable with your MySQL password.

## Running the Project
1. Open the Java project in IntelliJ IDEA.
2. Add MySQL Connector/J to the project dependencies.
3. Configure the `DB_PASSWORD` environment variable in the run configuration.
4. Run `API.java`.
5. Open the frontend `index.html` in your browser.
